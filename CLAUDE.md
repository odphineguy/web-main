# Project Rules — abemedia.online

## No emojis, ever

Never use emoji characters anywhere in this codebase — no UI copy, component code, messages/*.json translation strings, comments, commit messages, or documentation. This is a hard rule, not a style preference.

Use lucide-react icons for UI affordances (e.g. theme toggle, phone icons) instead of emoji glyphs. Typographic symbols that are not emoji (✓, →, ·, —) are fine and unaffected by this rule — the distinction is pictograph/color emoji vs. plain Unicode punctuation and dingbats.

If you find an emoji anywhere in this repo, remove it on sight even if unrelated to the current task.
